Custom KeybindingsMap a Vim key sequence to an app action
Normal mode is the most reliable place for these — works for a single key or a multi-key sequence, as long as its first key isn't already a Vim command by itself (true for most plain letters; try an unused key like Q or a multi-key combo starting with one). Insert mode only cleanly supports a single trigger key (e.g. ;) — a multi-key insert sequence can leave its last character typed into the note, a CodeMirror Vim-mode quirk.
